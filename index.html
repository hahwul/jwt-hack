Commands

Recon, attack, and report without switching tools.

Each step of a JWT assessment is a subcommand. They share flags, config, and output format, so the result of one feeds the next.

01Inspect

decodeHeader, claims, timestamps. Handles JWE and DEFLATE. verifyCheck a signature with a secret or PEM key, optionally exp. scanRun every check at once and export a JSON or HTML report.

02Attack

crackDictionary, brute force, or targeted kid/jti guessing. payloadnone-alg, alg confusion, kid injection, jku/x5u, claim tampering. jwksFetch, spoof, and test key sets. Find stale keys after rotation.

03Forge

encodeSign with any of 13 algorithms, add headers, compress, or emit JWE. shellInteractive REPL with history and completion for longer sessions.

04Automate

serverREST API with optional API key, for scanners and CI. mcpExpose jwt-hack as tools to Claude and other MCP clients. --jsonStable machine output for jq, scripts, and pipelines.
